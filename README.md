# TitanGra16 GitHub Portfolio

Sito statico di copertina per il profilo GitHub di TitanGra16, ispirato alla struttura a sezioni di Specy e costruito con HTML, CSS e JavaScript vanilla.

## Pubblicazione su GitHub Pages

1. Crea una repository chiamata `TitanGra16.github.io`.
2. Carica questi file nella root della repository.
3. Vai in `Settings > Pages` e pubblica dal branch principale.

Il sito funziona anche aprendo direttamente `index.html` nel browser.
